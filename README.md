# droidblox-kt
DroidBlox rewritten in Kotlin **(WIP)**

This project is meant to replace the slow python implementation of DroidBlox.
This is also meant to replace the root method implemented right now with a patched apk of Roblox.
This repository only contains the manager app used to communicate with DroidBlox.

Once this application is stable, it will be merged into the [main repository](https://github.com/meowstrapper/DroidBlox)
